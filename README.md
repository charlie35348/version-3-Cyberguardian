Cyber Guardian
Cyber Guardian is an interactive cyber security awareness platform that transforms cyber security education into an engaging, gamified learning experience. Users complete challenge-based quizzes covering common online threats while earning points, tracking progress, and competing on a leaderboard.

Project Overview
Cyber Guardian was developed to help users improve their understanding of online safety through interactive learning. Instead of traditional reading-based content, the platform uses challenge-driven gameplay to teach users how to recognise and respond to cyber security threats.

Players create a profile, choose a threat category, complete scenario-based questions, and earn points based on their performance. Scores are tracked and displayed on a leaderboard to encourage engagement and continuous learning.

Cyberbullying Prevention
Understand online safety, recognise harmful online behaviour, and learn appropriate response strategies.
